## 1. 포인터를 배열처럼 사용

- 배열 이름은 **첫 번째 원소의 주소**이다. 그래서 `p = a;` 로 포인터에 넣을 수 있다.
- 포인터 `p` 도 `p[0]`, `p[1]` 처럼 **배열과 똑같이 인덱스로 사용**할 수 있다.
- 즉, **배열은 결국 포인터로 구현된다.**

```c
int a[] = { 10, 20, 30, 40 };
int *p;

p = a;
printf("a[0]=%d a[1]=%d a[2]=%d \n", a[0], a[1], a[2]);
printf("p[0]=%d p[1]=%d p[2]=%d \n\n", p[0], p[1], p[2]);
```

실행 결과
```
a[0]=10 a[1]=20 a[2]=30
p[0]=10 p[1]=20 p[2]=30
```
전체 소스: `01_pointer_as_array.c`

## 2. 배열 매개 변수

### 일반 매개 변수 vs 배열 매개 변수
```c
// 매개 변수 x에 기억 장소가 할당된다 (값이 복사됨)
void sub(int x) { ... }

// b에 기억 장소가 할당되지 않는다 (배열이 복사되지 않음)
void sub(int b[]) { ... }
```
- **왜?** 배열 전체를 함수로 복사하면 시간이 많이 걸리기 때문이다.
- 그래서 배열을 넘기면 **배열의 주소(포인터)만 전달**된다.
- **배열 매개 변수는 포인터로 생각할 수 있다.** 다음 두 가지는 완전히 같다.

```c
void sub(int b[], int n);
void sub(int *b, int n);
```

### 함수 안에서 바꾸면 원본이 바뀐다
```c
void sub(int b[], int n)
{
    b[0] = 4;
    b[1] = 5;
    b[2] = 6;
}
```
`main()` 에서 `a = {1, 2, 3}` 을 넘기면

```
1 2 3
4 5 6
```
전체 소스: `02_array_param.c`

```c
void update_array(int x[])
{
    x[0] = 99;
}
```
실행 결과: `a[0]=99 a[1]=20 a[2]=30`

전체 소스: `03_update_array.c`

> 배열의 크기는 함수로 전달되지 않으므로, 보통 `n` 처럼 **크기를 따로 넘긴다.**

## 3. 핵심 예제: 배열 요소 합

- 배열을 인수로 받아서 원소의 합을 계산해 반환하는 함수 `get_sum()` 을 작성한다.
- `int data[] = { 10, 20, 30, 40, 50 };` → 결과 `150`

### 배열 매개 변수 버전
```c
int get_sum(int a[], int n)
{
    int i;
    int sum = 0;
    for (i = 0; i < n; i++)
        sum += a[i];
    return sum;
}
```
전체 소스: `04_get_sum_array.c`

### 포인터 매개 변수 버전
```c
int get_sum(int *p, int n)
{
    int i;
    int sum = 0;
    for (i = 0; i < n; i++)
        sum += *(p + i);    // p[i] 와 같다
    return sum;
}
```
전체 소스: `05_get_sum_pointer.c`

| 표현 | 의미 |
|------|------|
| `a[i]` | i번째 원소 |
| `*(p + i)` | p가 가리키는 곳에서 i칸 뒤의 원소 (= `p[i]`) |

## 4. 실습: 평균

- 학생들의 성적을 **난수로 생성**하고 평균을 계산한다.
- 함수를 셋으로 나눈다.
  - `get_data()` : 배열에 0~99 난수를 채운다
  - `print_data()` : 배열을 출력한다
  - `get_mean()` : 평균을 반환한다
- `#define N_DATA 10` 으로 데이터 개수를 정한다.
- `srand((unsigned)time(NULL));` 로 실행할 때마다 다른 난수가 나오게 한다.

```c
double get_mean(double data[])
{
    int i;
    double sum = 0.0;
    for (i = 0; i < N_DATA; i++) {
        sum += data[i];
    }
    return sum / N_DATA;
}
```

실행 결과 예 (난수라 매번 다르다)
```
( 66.00 93.00 7.00 29.00 14.00 28.00 44.00 55.00 53.00 83.00 )
평균값은 47.200000
```
전체 소스: `06_mean.c`

> PDF 코드는 `double data[20];` 으로 선언했지만 실제로는 `N_DATA`(10)개만 사용한다.

## 5. 점검 문제

1. 함수에 매개 변수로 변수의 **복사본**이 전달되는 것을 ____ 라고 한다.
   → **값에 의한 호출 (call by value)**
2. 함수에 매개 변수로 변수의 **원본**이 전달되는 것을 ____ 라고 한다.
   → **참조에 의한 호출 (call by reference)**
3. 배열을 함수의 매개 변수로 지정하는 경우, 배열의 복사가 일어나는가?
   → **아니다.** 배열의 주소만 전달되므로 함수 안에서 바꾸면 원본이 바뀐다.

## 6. 자율 주행 자동차: 센서 데이터 받기

- `getSensorData()` 를 호출해서 **3개의 double형 데이터**를 받는다.
- 함수는 값을 하나만 `return` 할 수 있지만, **포인터(배열)를 넘기면 여러 값을 돌려받을 수 있다.**

```c
// 0부터 99까지의 난수(실수형태)를 발생하여 크기가 3인 배열 p에 저장한다.
void getSensorData(double *p)
{
    p[0] = rand() % 100;
    p[1] = rand() % 100;
    p[2] = rand() % 100;
    return;
}
```

실행 결과 예
```
왼쪽 센서와 장애물과의 거리: 41.000000
중간 센서와 장애물과의 거리: 67.000000
오른쪽 센서와 장애물과의 거리: 34.000000
```

### 주의 (직접 확인함)
- PDF 정답 코드는 `rand()` 를 쓰는데 `#include <stdlib.h>` 가 빠져 있다. 예제 소스에는 추가했다.
- `srand()` 를 부르지 않으면 실행할 때마다 같은 값이 나온다. 예제 소스에는 `srand((unsigned)time(NULL));` 을 추가했다.

전체 소스: `07_sensor.c`

## 7. 문자열 표현 방법과 NULL 문자

- **문자열(string)**: 문자들이 여러 개 모인 것
  - `"A"`, `"Hello World!"`, `"변수 score의 값은 %d입니다"`
- **하나의 문자**는 `char` 형 변수로, **문자열**은 `char` 형 **배열**로 저장한다.

```
H | E | L | L | o | \0
```

### NULL 문자
- **NULL 문자(`'\0'`)는 문자열의 끝을 나타낸다.**
- 끝 표시가 없으면 문자열이 어디서 끝나는지 알 수 없다.

```
str[0] str[1] str[2] str[3] str[4] str[5] ...
  s      e      o      u      l     \0      ← 여기서 끝: "seoul"
```
`\0` 이 없으면 뒤의 쓰레기 값까지 읽어서 `"seoul#"`, `"seoul#%"`, ... 처럼 될 수 있다.

```c
char str[10] = "seoul";
for (i = 0; str[i] != '\0'; i++)
    printf("str[%d] = '%c'\n", i, str[i]);
```
전체 소스: `08_null_char.c` (보충 예제)

> 문자열을 저장할 배열은 **글자 수 + 1(`\0` 자리)** 이상이어야 한다.

## 8. 문자열 상수

- **문자열 상수**: `"HelloWorld"` 처럼 소스 안에 직접 쓴 문자열
- 문자열 상수는 메모리의 **텍스트 세그먼트(text segment)** 에 저장된다.

```c
char *p = "HelloWorld";
```
- 이 문장은 문자열을 `p` 에 복사하는 것이 아니라, **텍스트 세그먼트에 있는 문자열 상수의 주소를 `p` 에 넣는 것**이다.

| 코드 | 가능? | 이유 |
|------|-------|------|
| `p[0] = 'A';` | ❌ | 텍스트 세그먼트(읽기 전용)에 쓰려고 해서 오류 |
| `strcpy(p, "Goodbye");` | ❌ | 위와 같음 |
| `p = "Goodbye";` | ✅ | 포인터가 **다른 문자열을 가리키게** 할 뿐 |

- 수정 가능한 문자열이 필요하면 `char s[] = "HelloWorld";` 처럼 **배열**로 선언한다. (배열에 복사본이 만들어진다.)

전체 소스: `09_string_constant.c` (보충 예제)

## 9. 문자열의 배열

- 문자열이 여러 개면(`"init"`, `"open"`, `"close"`, ...) **2차원 char 배열**로 저장하는 것이 편하다.

```c
char s[3][6] = {
    "init",
    "open",
    "close"
};
```
```
       [0] [1] [2] [3] [4] [5]
s[0]    i   n   i   t  \0
s[1]    o   p   e   n  \0
s[2]    c   l   o   s   e  \0
```
- **행** = 문자열 하나, **열** = 문자. 열 크기는 가장 긴 문자열 + 1(`\0`) 이상이어야 한다.
- `s[i]` 는 i번째 문자열이므로 `printf("%s", s[i])` 로 출력할 수 있다.

```c
char menu[5][10] = { "init", "open", "close", "read", "write" };
for (i = 0; i < 5; i++)
    printf("%d 번째 메뉴: %s \n", i, menu[i]);
```
전체 소스: `10_menu_2d.c`

## 10. 실습: 암호 강인성 조사

- 암호 안에 **대문자, 소문자, 숫자가 모두** 들어 있는지 검사한다.
- 셋 중 하나라도 없으면 다시 입력받는다.

### 핵심 포인트
- 플래그 변수 `is_upper`, `is_lower`, `is_digit` 을 0으로 두고, 해당 문자를 찾으면 1로 바꾼다.
- `strlen(password)` 로 문자열 길이만큼 반복한다. (`#include <string.h>`)
- 문자의 종류는 **아스키 코드 범위**로 비교한다.

```c
if (password[i] >= '0' && password[i] <= '9')
    is_digit = 1;
else if (password[i] >= 'A' && password[i] <= 'Z')
    is_upper = 1;
else if (password[i] >= 'a' && password[i] <= 'z')
    is_lower = 1;
```
- 세 플래그가 모두 1이면 `"적정한 암호입니다."` 를 출력하고 `break` 로 빠져나온다.

실행 결과 예
```
암호를 생성하시오: abc
숫자, 소문자, 대문자를 섞어서 암호를 다시 만드세요!
암호를 생성하시오: Abc1
적정한 암호입니다.
```
전체 소스: `11_password.c`

> `<ctype.h>` 의 `isdigit()`, `isupper()`, `islower()` 를 써도 된다. (라이브러리 함수 정리 노트 참고)

## 11. 주의할 점

### 문자열 대입
```c
char s[20];
s = "hello world";     // ❌ 컴파일 오류: 배열 이름에는 대입할 수 없다
```
```c
char *s;
s = "hello world";     // ✅ 포인터는 문자열 상수를 가리킬 수 있다
```
- 배열에 문자열을 넣으려면 `strcpy(s, "hello world");` 를 쓴다.

### 문자열 입력
```c
char s[20];
scanf("%s", s);        // ✅ 배열에 저장 공간이 있다
```
```c
char *s;
scanf("%s", s);        // ❌ 위험: s는 초기화되지 않아 아무 곳이나 가리킨다
```
- 포인터는 **저장 공간이 아니다.** 입력은 반드시 공간이 있는 배열(또는 할당한 메모리)에 받는다.

> (PDF에는 코드만 있고 정답 표시가 없어서 보충한 것이다.)

## 핵심 요약

| 주제 | 핵심 |
|------|------|
| 배열과 포인터 | 배열 이름 = 첫 원소 주소, `p[i]` 와 `*(p+i)` 는 같다 |
| 배열 매개 변수 | `int b[]` = `int *b`, 복사되지 않고 주소만 전달, 원본이 바뀜 |
| 배열 크기 | 함수로 전달되지 않으므로 `n` 을 따로 넘긴다 |
| 여러 값 반환 | 포인터(배열)를 넘겨서 함수가 값을 채우게 한다 (`getSensorData`) |
| 문자열 | `char` 배열 + 끝의 `'\0'` |
| 문자열 상수 | 텍스트 세그먼트에 저장, `char *p = "..."` 로 가리키면 수정 불가 |
| 문자열의 배열 | 2차원 `char` 배열, `s[i]` 가 i번째 문자열 |
| 주의 | 배열에는 `=` 대신 `strcpy`, 초기화 안 된 포인터로 `scanf` 금지 |
